# jfreitas.dev

## Requirements

### [NodeJs](https://nodejs.org/en/)

`Expected version: >=20.15.1`

### [Bun](https://bun.sh/)

## Getting Started

### Install dependencies

```bash
bun install
```

Run the development server:

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
